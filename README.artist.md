# StreamThing Experience Direction

StreamThing should feel like a focused desktop utility for selective synchronization.

## Keep

- dense, practical layout;
- clear hierarchy between settings, status, tree, filters and save actions;
- plain labels;
- technical terms only when they are exact (`Syncthing`, `.stignore`, `API`);
- hover help for persistent controls.

## Avoid

- framework starter branding;
- marketing pages instead of the tool;
- implicit global scans on every filesystem event;
- promising media streaming while v1 is scoped to Syncthing and `.stignore`.
