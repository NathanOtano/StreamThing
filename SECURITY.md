# Security Policy

## Supported Versions

The public `0.1.x` line is a first source release. Security fixes will target the latest public tag.

## Reporting a Vulnerability

Please open a private GitHub security advisory on this repository if available, or create a minimal issue that describes the affected public version without sharing secrets or private folder paths.

Do not include real `.stignore` files, local folder names, machine names, API keys, or private Syncthing configuration in public reports.
